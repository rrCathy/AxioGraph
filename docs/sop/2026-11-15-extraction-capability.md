## 2. 分能力项

### 2.1 汉字保真（层 1）
- 正文汉字零丢失（recall 1.0000，最差页也是 1.0）。图区吞进的正文行、页眉分离、大运算符吸附都不丢字。
- 行内上下标由 `rawdict` 字符 size/基线重建（`_{}`/`^{}`）；TeX 数学字体碎片页整页转 RapidOCR（判据：数学字体孤立行 ≥20 且占比 ≥0.25，带 `span.math` 字体条件）。

### 2.2 公式识别
- **分块**：ONNX 版面模型出区域；孤立大运算符行自动吸附进公式区域并扩框（修「∩ 落在框外 0.05pt」类缺符号）；孤立 `∩ _{E⊂N◁G} N` 行自动粘合。
- **带中文注释的显示公式**（`V₀ := ∅, … 如果α是极限序数`）：`origin=layout:formula` + 汉字占比 <0.35 + 含 `:=` 的块豁免 CJK 降级；texify 读不出的自动退回正文（不占公式名额）。
- **幻觉守门**（`latex_valid`）：间距命令（`\quad` 等）不参与直方图——曾把合法的 `\xrightarrow{\quad G\quad}` 误拒；`\hat`×85、`\bf`×30、退化填充、纯方程号仍被拒。
- **定向抢救**（`_salvage_annotated`）：对带注释公式剥替身字形（`\nmid_{\mathcal{H}}`/`\nwarrow` 簇、`\frac{\mathbb{R}}{\mathbb{R}}` 自分数、孤儿下标、`\tag`/`(\mathbf{2.6})` 方程号残渣），结构平衡才接受；抢救后不平衡的整块留正文（正文里汉字可读）。
- **解码循环**：交换图曾让 texify 跑满 1024 tokens（单块 25-30s、1533 字符垃圾）；`_LoopStop` 只在最后 32 token 构成整周期时停。`no_repeat_ngram_size` 方案已否决（改错括号/吐幻觉）。

### 2.3 交换图 vs 示意图（2026-11-15 新增）
- 判据：PDF 矢量箭头头。实测 12 页人工标注——交换图 **3-16** 个、示意图 **0-1** 个、真公式 **0** 个。
- 交换图 → `DIAGRAM` 块：不喂 texify（零垃圾、零解码循环），标签按二维位置渲染 + 关系清单（如 p385：`A —ι→ Â` / `A —f→ B` / `Â —∃! f̂→ B`）；解析不全时保留二维标签布局兜底。
- 示意图 → `FIGURE`：继续排除，不进提取文本。已核实的边界：Hasse 格图（无态射箭头）与位图插图（0 个矢量绘图）按规则本就排除。
- 拆开的字形自动合并（`∃! ˆ` + `f` → `∃! f̂`；`Aˆ` → `Â`）。

### 2.4 页级管道与交互
- 上传 PDF 只建页索引；1/2/3 页窗口（或自动模式）→ pending 候选 → 人工确认后入图（带页码、`source_quote`、`created_by=human`）。
- **两阶段加载**：`/render` 0.107s、`/meta` 0.136s 先出原页；内容提取（未缓存页 3-16s）并发在后，右栏骨架占位。smoke 有断言防识别逻辑回流快路径。
- 后台预取后两页（预取后切页 0.07s）；识别/页文本 lazy 缓存，`LAYOUT_VERSION` 控制失效。

## 3. 口径红线（汇报时必须遵守）

1. **99% 只在「正文汉字」口径成立**。公式语义 exact 口径远未到 99%（等价写法被 exact 计失分），语义 F1 各层为 0.876（中文书）/ 0.923（arXiv）/ 0.967（引擎）。
2. **英文 arXiv ≠ 中文数学书**：ONNX 版面模型在英文论文上几乎圈不出 formula region（泛化短板，未改）。
3. 归一化必须真值/预测**两侧同做**（`\xrightarrow`↔`\stackrel`、`{\cal C}`↔`\mathcal{C}`、`\emptyset`↔`\varnothing` 等）；SUMMARY 同时报 raw 与 normalized。
4. 定位只用 PDF 文本层可见字符反查，绝不依赖 OCR 输出（否则识别越差评测越歪）。
5. 含 `\text{中文}` 的公式失分是模型读不了汉字的**已知边界**，不计为「识别错」单独口径报。

## 5. 已知边界（规则侧已到顶的部分）

1. **texify 读不了公式里的中文**：带 `\text{中文}` 的公式 F1 0.65；p28 aleph 定义式抢救后不平衡，整块留正文（0.26）。再提升需换更强公式 OCR 权重或人工黄金集。
2. **英文论文版面泛化**：ONNX 版面模型在英文论文上几乎圈不出 formula region。
3. **稳态 12-15s**：来自每页公式块**串行**推理；要再快需 batch generate + 逐序列 stopping（`_LoopStop` 目前只判 batch 第 0 条）。
4. **扫描书**：唯一真扫描件（340 页零文本层）走 RapidOCR 兜底；无书签且目录解析失败的书仍需手动「自动识别」。
5. 版面缓存覆盖 135/1456，跳到未缓存页首访 3-16s（原页不受影响）。
